# OmniRoute: what it is and how to leverage it with omp

Research date: 2026-09-14. Sources: [github.com/diegosouzapw/OmniRoute](https://github.com/diegosouzapw/OmniRoute) (66k stars, MIT), [omniroute.online](https://omniroute.online/), [cheaperinference.com](https://www.cheaperinference.com/), plus price cross-checks against the models.dev catalog snapshot (`.omp-pricing-extract.json`).

## 1. Disambiguation — three products share the name

| Product | What it is | Cost |
|---|---|---|
| **OmniRoute** (diegosouzapw/OmniRoute) | Self-hosted MIT-licensed AI gateway. One OpenAI/Anthropic/Gemini/Responses-compatible endpoint (`http://localhost:20128/v1`) fronting **352 providers** (~152 marked free), 1,300+ models. | **$0** (software). You pay only the upstream providers you connect; many routes are free tiers or keyless. |
| **Cheaper Inference** | OmniRoute's hosted/commercial companion. Cost-ranked marketplace reselling PAYG tokens below list price. | PAYG; advertised ~50–70% below list on select models; $10 bonus credit when you fund $5. |
| **OmniRouter.cc / OmniRouter.li** | Unrelated subscription coding-agent routers ($20–$200/mo credit plans). Not covered further. | — |

This analysis is about the first two.

## 2. What OmniRoute actually does (relevant to an omp user)

omp already supports ~70 providers natively. OmniRoute's incremental value to an omp setup is **not** provider count — it's four mechanical things omp doesn't do:

1. **Quota-aware auto-fallback.** When a target model is unavailable, rate-limited, or out of quota, OmniRoute automatically selects the next healthy target for the same model name. omp has no native cross-provider fallback for a single logical model; with OmniRoute as one custom provider, `omniroute/glm-5.2` transparently fails over across every upstream that serves GLM-5.2. 3-layer resilience: provider circuit breaker → connection cooldown → model lockout.
2. **Free-tier stacking.** It catalogs 444 free-tier entries across 34 recurring pools (Mistral ~1B, Nara 210M, LLM7 150M, Groq per-model caps, Cerebras 1M tok/day, NVIDIA NIM, Cloudflare, SiliconFlow, OpenCode Zen, Kilo, Qoder, Pollinations keyless…) and claims a pool-deduplicated **~1.47B free tokens/month** (~2.1B first month with signup credits). It rotates across them so you never manually juggle rate limits. `X-OmniRoute-Decision` headers show which strategy/provider served each request.
3. **Context compression.** RTK + Caveman 12-engine pipeline claims 15–95% reduction of eligible context (tool-heavy example: ~89%). For agentic coding — where input/cache-read dominates spend — this directly cuts the token bill on any PAYG upstream. Opt-in per route; note compression rewrites prompts, so it can degrade quality on precision tasks (omp's own docs advise against prompt mangling for coding agents; treat as a lever, not a default).
4. **One billing/observability plane.** Cost telemetry headers on every response, per-key USD spend quotas, usage dashboard — across all upstreams, including subscription/coding-plan providers which read $0 in analytics.

Also relevant: `omniroute configure <tool>` writes tool-native config; `omniroute run <cli>` launches CLIs with injected credentials; encrypted key storage; MITM/TPROXY for CLIs that ignore proxy env.

## 3. How to wire it into omp

omp speaks to any OpenAI-compatible endpoint via a custom provider in `~/.omp/agent/models.yml` (see `omp://providers.md` "custom providers"). Two options:

**A. OmniRoute as a provider (recommended).** Run OmniRoute locally (`npm install -g omniroute && omniroute`), then add to `models.yml`:

```yaml
providers:
  omniroute:
    baseUrl: http://localhost:20128/v1
    api: openai-completions
    apiKey: "any-nonempty-string"     # local gateway; keyless quick start works
    authHeader: true
    models:
      - id: glm/glm-5.2
        name: GLM 5.2 (omniroute)
        contextWindow: 200000
        maxTokens: 262144
        # ...same model fields as your existing baseten entries
```

Point the model IDs at OmniRoute combo names (`auto/coding`, `auto/coding:high`, or a specific provider/model) so fallback/free-tier rotation happens behind one stable name. **Current repository status:** `configure_omp` emits one native ordered fallback ladder for Copilot, Cursor Grok 4.6, Grok Build/SuperGrok Grok 4.6, Codex, Baseten, and the latest OpenRouter DeepSeek Flash route; OmniRoute remains optional and is not generated by the bootstrap scripts. If it is adopted, add its provider block to `configure_omp` rather than editing `~/.omp/agent/models.yml` directly, because hand edits are overwritten on the next setup run.

**B. Cheaper Inference as a provider.** Same shape, but `baseUrl` = their hosted endpoint with a real API key. This is a PAYG reseller, so it behaves like any other hosted provider (no fallback across *your* subscriptions, but cheaper unit prices — §4).

| gpt-5.6-terra | $0.80/$4.80 | 1.5/2 (xpersona, suspect); official 2/12 | xpersona | CI genuinely 60% off official |
| glm-5.3-flash | not listed | 0.015/0.05 (merge-gateway); official 0.075/0.25 | merge-gateway | already ultra-cheap direct from Z.ai — no CI needed |

**Pattern:** CI's real edge is **discounted OpenAI/Anthropic frontier access** (GPT-5.6 Terra at $0.80/$4.80 vs $2/$12 official is the standout). For budget Chinese-lab models (GLM, DeepSeek, Kimi, MiniMax) official APIs are already so cheap that a middleman adds little.

**Risk note [INFERENCE]:** prices below official vendor list (60% off OpenAI) imply upstream routes that are unofficial — likely pooled subscription accounts or regional arbitrage. That carries: (a) ToS/account-ban risk upstream, (b) availability/latency variance, (c) your code transiting an unvetted third party. Acceptable for scratch/personal code; think twice for proprietary codebases. OmniRoute itself marks 13 free providers "avoid" in its own terms-risk catalog — the project is at least honest about this class of risk.

## 5. How this fits the $100/month budget

OmniRoute is a **budget multiplier, not a line item** ($0 software). Concrete leverage, in order of value:

1. **Free-tier floor for cheap/boilerplate work.** Wire `auto/coding` (or a custom combo of Cerebras GLM-4.7, NVIDIA NIM, Groq, SiliconFlow free, OpenCode Zen) as omp's `--smol` model and for prewalk/grunt work. The ~1.47B claimed free tokens/mo is pool-deduplicated and re-audited bi-weekly, but treat free tiers as bursty/unreliable — which is exactly what fallback fixes. Realistic expectation: offload 20–40% of trivial tokens to $0.
2. **Fallback insurance on paid routes.** Define combos like `glm-5.2 = [zai official → nano-gpt → fireworks]` so a provider outage degrades to the next-cheapest instead of stalling a long agent run. This protects the paid budget from waste-on-retries.
3. **Frontier access at 60% off via Cheaper Inference.** If the $100 plan includes a frontier-model allowance (e.g. GPT-5.6-Terra or Claude for hard tasks), routing that slice through CI stretches it ~2.5×. E.g. $20/mo of frontier budget buys ~$50 of official-list usage. Keep it to the hard-task slice only.
4. **Compression on PAYG routes.** Enabling RTK+Caveman on long agentic sessions could cut input spend 15–50% on routes where cache-read is weak. Test on your own traces first; skip it on providers with strong cache pricing (cache-read at 5–10% of input makes compression nearly pointless and quality-risky).
5. **Quota pooling for subscription plans.** If the budget ends up including a coding-plan subscription (GLM/Kimi/MiniMax), OmniRoute reads them as $0-cost routes and can fall back across plan quota + PAYG + free tiers behind one model name — the cleanest way to spend plan quota before PAYG dollars. **This is arguably its best omp use case** (matching the subscription-first strategy the budget analysis recommends).

## 6. Recommendation

- **Adopt OmniRoute as a local sidecar** (it's free, MIT, one npm install) and register it as one custom omp provider for: smol/prewalk work (free-tier combos), fallback chains on budget workhorses, and subscription-quota-first routing.
- **Keep the primary budget models direct from official APIs** (Z.ai, DeepSeek, Moonshot) — official pricing on these is already at/below any reseller floor and avoids grey-market risk on your daily drivers.
- **Use Cheaper Inference only for the frontier slice** (GPT-5.6-Terra 60% off is the verified standout) and only for non-sensitive code, capped explicitly in omp's per-model budget or CI's per-key USD quota.
- **Do not adopt OmniRouter.cc/omnirouter.li** — unrelated subscription routers; dominated for this budget by GLM/Kimi coding plans + PAYG mix.
- Integration point for this dotfiles repo: extend `configure_omp` in `lib/shared.sh` to emit the omniroute provider block into `models.yml`.
